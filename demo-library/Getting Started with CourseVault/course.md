# Getting Started with CourseVault

This is a **sample course** that ships with CourseVault so you can see how a
library folder is laid out. It is not a real course — replace it with your
own folders.

## How this folder is organised

```
Getting Started with CourseVault/
  course.md                  <- this file: the course description
  01 - The basics/
    01 - What is CourseVault.md
    01 - What is CourseVault.srt
    01 - What is CourseVault/     <- downloads / resources for that lesson
      starter-checklist.txt
    02 - Organising your library.md
```

To add a video lesson, drop an `01 - What is CourseVault.mp4` next to the
`.md` file. CourseVault will pick it up automatically — no renaming needed.
