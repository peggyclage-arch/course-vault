# What is CourseVault?

CourseVault is a **desktop course library**. You point it at a folder on your
computer, and it turns that folder into a catalogue of courses, modules and
lessons — with a video player, notes, subtitles, downloads and progress
tracking.

## The three ideas behind it

- **Your files stay yours.** Everything lives in a folder you control.
  There is no upload, no account and no cloud.
- **Progress is remembered locally.** Where you left off in a video, which
  lessons you finished, which folder you last opened — all stored in a JSON
  file on this PC, nothing else.
- **Plain folders are the database.** A course is a folder, a module is a
  folder, a lesson is a set of files that share a name. If you can organise
  folders, you can build a course.

## Try it

1. In CourseVault, choose this `demo-library` folder as your library.
2. Open this lesson, read the notes, and mark it complete.
3. Add your own course folder next to this one and watch it appear.
